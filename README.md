## Project Description
This project aims to develop a robot car controlled
by spoken commands using a microcontroller such
as the ESP32-S3.

## Objectives
- Recognize spoken commands to control robot movement.
- Send movement commands to the robot controller,
  potentially via UART.
- Implement speech synthesis for verbal feedback.
- Integrate and test the hardware and software.
- Document the system architecture, data flow,
  and source code.

## Planned Hardware
- ESP32-S3 or another suitable microcontroller
  (to be confirmed)
- University robot car (exact model to be confirmed)
- Microphone or offline speech recognition module
- Speaker or speech synthesis module
